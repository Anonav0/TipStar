**Tip Calculator App** 🧮
=========================

**Description**
---------------

This is a simple **Tip Calculator** Android app built using **Java** and **XML**. The app allows users to:

-   Enter a bill amount
-   Adjust the tip percentage using a **SeekBar**
-   Calculate and display the **tip amount** and **total bill**

* * * * *

**Project Structure**
---------------------

-   **Main Java File**:\
    Path:  [`app/src/main/java/com/swarnavo/tipstart/MainActivity.java`](app/src/main/java/com/swarnavo/tipstart/MainActivity.java)

-   **Main XML Layout**:\
    Path: [`app/src/main/res/layout/activity_main.xml`](app/src/main/res/layout/activity_main.xml)

* * * * *

**Features**
------------

✔ Enter the **bill amount**\
✔ Adjust the **tip percentage** using a **SeekBar** (0% - 50%)\
✔ Click "Calculate Tip" to see **Tip Amount & Total Bill**\
✔ Simple and user-friendly **UI**

* * * * *

**Installation Instructions**
-----------------------------

1.  **Clone the repository from GitHub**

    ```
    git clone https://github.com/your-username/TipCalculator.git

    ```

2.  **Open the project in Android Studio**
3.  **Run the app** on an emulator or a physical device

* * * * *

**How to Use**
--------------

1.  **Enter** the bill amount in the input field
2.  **Move the SeekBar** to select a tip percentage
3.  **Click "Calculate Tip"** to display the tip and total amount
